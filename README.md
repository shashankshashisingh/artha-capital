# Artha Capital Website

A responsive single-page static website for Artha Capital, built with HTML and CSS.

## Publish with Netlify

1. Sign in at https://app.netlify.com/
2. Choose **Add new site → Import an existing project**.
3. Connect GitHub and select `shashankshashisingh/artha-capital`.
4. For this static HTML site, leave the build command empty and set the publish directory to the repository root (`.`).
5. Deploy the site. Netlify can automatically redeploy on future commits.

## Before using commercially

- Replace `hello@arthacapital.com` with the verified company contact email.
- Confirm the legal entity name, regulatory disclosures, investment claims, and privacy requirements.
- This is a design starter and does not imply regulatory registration or an actual investment track record.

The hero image and fonts load from Unsplash and Google Fonts, so those assets require an internet connection.
